# Проверки и ограничения

На Apple M1 Pro, macOS 27.2 и одном дисплее прошли основной набор тестов, сборка, проверка подписи и образа DMG. Копия приложения из образа запустилась с отдельными настройками.

Скрипты замера движения прошли для текущих исходников с локально предоставленными предыдущими версиями. Медиана возраста представленного положения окна составила 50,06 мс, p95 — 58,05 мс.

Тест перехода уточки исправлен с учётом продолжительности прогулки и прошёл. Тест жизненного цикла прошёл 137 проверок, тест ввода — 35.

Проверки GPU-симуляции, украшений, рендера, широких окон и осыпания прошли на собственных тестовых сценах.

Отдельно не проверены macOS 14, второй физический дисплей, установка на другом Mac и длительная стабильность. Системные переходы между рабочими столами, сон, режимы питания и VoiceOver требуют дополнительной проверки.
