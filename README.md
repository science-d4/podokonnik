# Podokonnik · Подоконник

**Интерактивные сезонные эффекты для рабочего стола macOS.** Сейчас доступна зима. Весенний, летний и осенний режимы в планах.

*Interactive snowfall on your Mac desktop, with spring, summer, and autumn modes planned.*

## Зимний режим

- Снег оседает на окнах, Dock и нижнем краю экрана. Быстрый рывок окна стряхивает сугроб.
- В игре можно смахивать снег варежкой, расчищать его лопатой и лепить снеговиков. Трактор периодически расчищает нижний край экрана.
- По рабочему столу гуляет уточка. В настройках можно включить гирлянды, ёлочки, северное сияние и падающие звёзды.

В обычном режиме эффекты пропускают клики в приложения. «Универсальный доступ» помогает учитывать положение окон и Dock. Базовый снегопад работает и без этого разрешения. Приложение работает офлайн, использует только геометрию окон и не запрашивает запись экрана.

## Установка

Нужен Mac с Apple Silicon и macOS 14 или новее.

1. Если готовая сборка есть на вкладке **Releases**, скачайте и откройте DMG. Для сборки из исходников используйте команды ниже.
2. Перетащите `Podokonnik.app` в «Программы» и откройте приложение оттуда.
3. Нажмите снежинку в строке меню, чтобы открыть настройки.

Сборка подписана ad-hoc. Шаги первого запуска и обновления описаны в [инструкции по установке](Resources/Installation-ru.txt).

## Сборка из исходников

Нужны Apple Command Line Tools с macOS SDK. Приложение использует Swift, AppKit, Metal и SpriteKit. Сторонних зависимостей нет.

Выполните команды из корня репозитория `podokonnik`.

```sh
bash Scripts/build.sh
open dist/Podokonnik.app
```

Чтобы упаковать приложение в DMG и получить файл SHA-256, выполните `bash Scripts/package-dmg.sh` после сборки. Образ появится в `dist/`. Основные тесты запускает `bash Scripts/test.sh`.
