# Podokonnik · Подоконник

**Интерактивные сезонные эффекты для рабочего стола macOS.** Сейчас доступна зима. Весенний, летний и осенний режимы в планах.

*Interactive snowfall on your Mac desktop, with spring, summer, and autumn modes planned.*

## Зимний режим

- Снег оседает на окнах, Dock и нижнем краю экрана. Быстрый рывок окна стряхивает сугроб.
- В игре можно смахивать снег варежкой, расчищать его лопатой и лепить снеговиков. Трактор периодически расчищает нижний край экрана.
- По рабочему столу гуляет уточка. В настройках можно включить гирлянды, ёлочки, северное сияние и падающие звёзды.

В обычном режиме эффекты пропускают клики в приложения. «Универсальный доступ» помогает учитывать положение окон и Dock. Базовый снегопад работает и без этого разрешения. Для снегопада интернет не нужен. Для автоматических обновлений приложение обращается к GitHub; их можно отключить в настройках. Приложение использует только геометрию окон и не запрашивает запись экрана.

## Установка

Нужен Mac с Apple Silicon и macOS 14 или новее.

1. Если готовая сборка есть на вкладке **Releases**, скачайте и откройте DMG. Для сборки из исходников используйте команды ниже.
2. Перетащите `Podokonnik.app` в «Программы» и откройте приложение оттуда.
3. Нажмите снежинку в строке меню, чтобы открыть настройки.

Сборка подписана ad-hoc. Шаги первого запуска и обновления описаны в [инструкции по установке](Resources/Installation-ru.txt).

## Сборка из исходников

Нужны Apple Command Line Tools с macOS SDK и интернет для первой загрузки Sparkle. Приложение использует Swift, AppKit, Metal, SpriteKit и Sparkle для обновлений; сборка проверяет контрольную сумму Sparkle.

Выполните команды из корня репозитория `podokonnik`.

```sh
bash Scripts/build.sh
open dist/Podokonnik.app
```

Чтобы упаковать приложение в DMG и получить файл SHA-256, выполните `bash Scripts/package-dmg.sh` после сборки. Образ появится в `dist/`. Основные тесты запускает `bash Scripts/test.sh`.

## Автоматические проверки и релизы

GitHub Actions запускает основные тесты и сборку на macOS с Apple Silicon для pull request и изменений в `main`. После успешных проверок изменений в `main` создаются тег и релиз с DMG, файлом SHA-256 и подписанным каналом обновлений. Версия на единицу больше последней версии в тегах или версии в `Resources/Info.plist`, если она выше; версия также записывается в приложение. Выпуск пропускается, если коммит не содержит последнюю выпущенную версию: задержавшийся запуск не заменит новый релиз старым кодом.

Канал обновлений подписывается ключом `SPARKLE_PRIVATE_KEY` в секретах GitHub Actions; при его отсутствии релиз не публикуется. Закрытый ключ нужно хранить и резервировать отдельно от репозитория.

Автообновление использует подписанные версии GitHub Releases. На вкладке «Обновления» можно посмотреть текущую и доступную версии, проверить обновления вручную и отключить автоматическую проверку и установку. Автоматическая установка перезапускает приложение; без сети оно продолжает работать. Для перехода с версии 1.7.2 или более ранней требуется один раз установить новую сборку вручную.

Графические тесты и проверки рабочего стола требуют отдельного запуска на Mac с активной графической сессией. Релиз подписан ad-hoc и не проходит нотариальную проверку Apple.
